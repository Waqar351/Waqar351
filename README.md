# Hi, I'm Waqar Hassan 👋

### AI / Machine Learning Researcher | Graph Machine Learning | Spatio-temporal AI | Explainable AI

I am an AI and Machine Learning researcher and Postdoctoral Researcher at the
University of São Paulo (USP), working at the intersection of **Graph Machine
Learning, spatio-temporal AI, Explainable AI, and Visual Analytics**.

My research focuses on developing machine learning methods for complex
real-world systems by combining **Graph Neural Networks, representation
learning, multimodal data integration, dimensionality reduction, and
interactive visualization**.

## 📚 Research Areas

Some of the problems I have worked on include:

**Graph Machine Learning**
  
Learning representations and predictive models over graph-structured
data.

**Spatio-temporal AI**
  
Modeling systems where both spatial relationships and temporal dynamics
are important.

**Explainable AI**
  
Understanding model behavior and learned representations through
interpretable analysis and visualization.

**Dimensionality Reduction & Visual Analytics**
  
Analyzing high-dimensional representations and developing interactive
methods for understanding complex data and machine learning results.

**Large-scale Data Processing**
  
Developing scalable data processing and machine learning workflows for
large datasets and high-throughput environments.
